# Student Risk and Advisor Briefing — portfolio adaptation

This team-built application demonstrates a student risk overview, filtered selection
and AI-assisted advisor briefings through a shared Python service, REST API and five
MCP tools. Advisors review generated text before acting. Scores are supplied model
signals; this portfolio makes no claim of calibrated probability or predictive accuracy.

The current branch bundles no student dataset, training pipeline, notebook output,
original reports or operational exports. Operators supply their own prediction view
and optional allowlisted context. There is no automatic mock fallback.
